# cafe-landing

동네 카페 **'카페 오늘'** 을 소개하는 한 페이지짜리 랜딩페이지입니다.
HTML, CSS, JavaScript만으로 만든 정적 사이트라서 설치하거나 빌드할 것이 없고, 파일을 브라우저로 열면 바로 동작합니다.

> 카페 이름, 소개 문구, 메뉴와 가격, 위치는 모두 예시입니다. 실제 가게에 쓰려면 아래 "내용 바꾸기"를 참고해 고쳐 주세요.

## 폴더 구성

```
cafe-landing/
├── index.html   페이지 구조와 내용
├── style.css    디자인(색상, 배치)과 모바일 대응
├── script.js    메뉴 펼치기·접기 동작
└── README.md    이 문서
```

## 페이지 구성

| 영역 | 내용 |
|---|---|
| 상단 메뉴 | 로고와 소개·메뉴·오시는 길 링크. 화면을 내려도 위에 붙어 따라옵니다 |
| 첫 화면 | 카페 이름, 한 줄 소개, "오늘의 메뉴 보기" 버튼 |
| 소개 | 매일 로스팅 · 직접 굽는 디저트 · 머물고 싶은 공간, 카드 3장 |
| 오늘의 메뉴 | 메뉴와 가격 목록. 처음에는 접혀 있고 버튼이나 상단 "메뉴" 링크로 펼칩니다 |
| 영업 정보 | 영업시간과 위치 |

화면 폭이 640px 이하인 모바일에서는 소개 카드와 영업 정보가 한 줄씩 세로로 쌓입니다.

## 실행

- `index.html`을 더블클릭해 브라우저로 엽니다.
- 로컬 서버로 보고 싶다면 폴더에서 `python -m http.server 8000`을 실행한 뒤 http://localhost:8000 에 접속합니다.

## 내용 바꾸기

| 바꿀 것 | 위치 |
|---|---|
| 카페 이름, 한 줄 소개 | `index.html`의 `<header class="hero">` 부분과 `<title>` |
| 소개 카드 3장 | `index.html`의 `<section id="about">` |
| 메뉴와 가격 | `index.html`의 `<section id="menu">` 안 `<li>` 항목 |
| 영업시간, 위치 | `index.html`의 `<section id="visit">` |
| 색상 | `style.css`의 `#4a3426`(진한 갈색), `#e0a96d`(버튼), `#f7f2ea`(배경) |

## 웹에 공개하기

이 레포는 비공개입니다. GitHub Pages로 누구나 볼 수 있는 주소를 만들려면 레포를 공개로 바꾼 뒤 **Settings → Pages**에서 `main` 브랜치의 루트(`/`)를 선택하면 됩니다. 주소는 `https://<계정>.github.io/cafe-landing/` 형식입니다.
